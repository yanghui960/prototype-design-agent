# 原型设计agent（prototype-design-agent）

让 AI 生成、审查、实现「千容AI工作台」风格高保真中文工作台界面的设计配方（Skill 技能包）。

> 本技能由 **千容AI** 个人工作台体系沉淀，此为**公开发布改编版**：
> 仅包含视觉规范、页面模式、提示词模板与验收流程等通用方法论，**不含**原项目私有素材、业务数据与本地路径。

## 这是什么

一套写给 AI（豆包、ChatGPT、Midjourney 等）看的设计协议。它让任意 AI 无需见过原项目，即可产出风格一致的高密度中文工作台原型图、实现规范或设计审查。

适用场景：本地单人运营工作台、数据密集的仪表盘、内容运营控制台、中文效率工具，以及任何希望继承「千容AI工作台」视觉系统的界面。

## 安装方法

把整个 `prototype-design-agent/` 目录放入你的 AI 客户端技能目录即可。

豆包（Doubao）桌面端示例：

```
<用户技能目录>/.user_skills/prototype-design-agent/
```

安装后，向 AI 说「用原型设计agent，按 千容AI 工作台风格生成 / 验收一张 XX 工作台界面图」即可触发。

## 使用方式

一次高保真原型输出包含四部分（详见 `SKILL.md` 的输出契约）：

1. 简短设计说明：界面 / 用户 / 任务 / 密度 / 布局主判断
2. 一条可直接给图片生成模型的提示词（或实现规范）
3. 精简组件清单
4. 桌面端 + 移动端验收清单

若环境中有可用的设计系统类技能（如 `ui-ux-pro-max`、`ui-craft-dense-dashboard` 等）可优先组合使用；不可用时直接按 `references/` 目录执行。

## 工作台演示原型（mockups/）

本仓库附带「千容AI工作台」全套高保真 HTML 演示原型，打开 `mockups/index.html` 即可体验完整页面：

| 页面 | 文件 | 说明 |
| --- | --- | --- |
| 日常仪表盘（入口） | `index.html` | 今日概览 / 待办 / 雷达机会 / 内容数据 |
| 雷达监控 | `radar-monitoring.html` | 信号指标 / 优先级提醒 / 平台热榜 / 机会详情抽屉 |
| 内容选题 | `topics.html` | 采集 / 洞察 / 选题 Tab、采集任务与结果抽屉 |
| 生产工作室 | `production-studio.html` | 富文本编辑 + AI 修订建议 + 手机预览 |
| AI 员工 | `ai-employees.html` | 本地智能体只读名册（内容 / 数据 / 系统组） |
| 知识库 | `knowledge-library.html` | 技能 / 工具 / 文件库，接入状态分组 + 详情抽屉 |
| 数据复盘 | `data-retro.html` | 指标条 / 导入面板 / 复盘报告 / 历史报告 |
| 设置 | `settings.html` | 大模型配置 / 平台连接 / 系统信息 |
| 系统日志 | `system-logs.html` | 运行日志表，级别 / 模块筛选 |

每个页面同时附 1440×900 的 PNG 预览（同名文件）。页面内数据均为**示例数据**，用于展示结构与交互；侧栏全站互链，抽屉 / Tab / 筛选均可点击体验。直接用浏览器打开 `mockups/index.html` 即可，无需启动任何服务。

## 核心视觉规范速览

| 项 | 值 |
| --- | --- |
| 页面背景 | `#F5F6F7` |
| 表面 / 侧栏 | `#FFFFFF` / `#F0F1F2` |
| 主文本 / 次文本 | `#202124` / `#686D76` |
| 主强调色（珊瑚） | `#E76852` |
| 圆角 | 卡片 ≤ 8px，控件约 6px |
| 布局 | 固定左侧栏（日常 / 运营 / 工具 / 系统）+ 顶栏 |

详细规范见 `references/visual-language.md`。
