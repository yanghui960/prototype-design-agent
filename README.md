# 原型设计agent（prototype-design-agent）

让 AI 生成、审查、实现「千容AI工作台」风格高保真中文工作台界面的设计配方（Skill 技能包）。

> 本技能由 **千容AI** 个人工作台体系沉淀，此为**公开发布改编版**：
> 仅包含视觉规范、页面模式、提示词模板与验收流程等通用方法论，**不含**原项目私有素材、业务数据与本地路径。

## 这是什么

一套写给 AI（豆包、ChatGPT、Midjourney 等）看的设计协议。它让任意 AI 无需见过原项目，即可产出风格一致的高密度中文工作台原型图、实现规范或设计审查。

适用场景：本地单人运营工作台、数据密集的仪表盘、内容运营控制台、中文效率工具，以及任何希望继承「千容AI工作台」视觉系统的界面。

## 安装方法

把整个 `prototype-design-agent/` 目录放入你的 AI 客户端技能目录即可。

豆包（Doubao）桌面端示例：

```
<用户技能目录>/.user_skills/prototype-design-agent/
```

安装后，向 AI 说「用原型设计agent，按 Mr 工作台风格生成 / 验收一张 XX 工作台界面图」即可触发。

## 使用方式

一次高保真原型输出包含四部分（详见 `SKILL.md` 的输出契约）：

1. 简短设计说明：界面 / 用户 / 任务 / 密度 / 布局主判断
2. 一条可直接给图片生成模型的提示词（或实现规范）
3. 精简组件清单
4. 桌面端 + 移动端验收清单

若环境中有可用的设计系统类技能（如 `ui-ux-pro-max`、`ui-craft-dense-dashboard` 等）可优先组合使用；不可用时直接按 `references/` 目录执行。

## 核心视觉规范速览

| 项 | 值 |
| --- | --- |
| 页面背景 | `#F5F6F7` |
| 表面 / 侧栏 | `#FFFFFF` / `#F0F1F2` |
| 主文本 / 次文本 | `#202124` / `#686D76` |
| 主强调色（珊瑚） | `#E76852` |
| 圆角 | 卡片 ≤ 8px，控件约 6px |
| 布局 | 固定左侧栏（日常 / 运营 / 工具 / 系统）+ 顶栏 |

详细规范见 `references/visual-language.md`。
